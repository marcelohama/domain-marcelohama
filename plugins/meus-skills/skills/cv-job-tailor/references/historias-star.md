# Banco de histórias STAR

Quarta fonte de fatos da skill. São as histórias que o Marcelo mantém em um board do Miro (competência x empregador), no formato Situação -> Tarefa -> Ação -> Resultado, com as palavras dele. Versão de 26/09/2026: quando o board mudar, este arquivo precisa ser atualizado à mão.

Use para o que os três PDFs não contam: o que foi feito para chegar ao resultado (runbook, comitê, cerimônias, método) e resultados que só aparecem aqui. Um marcador de CV aproveita a Ação e o Resultado; Situação e Tarefa ficam para a entrevista.

Os nomes de colegas foram retirados. Histórias sobre uma pessoa específica (atrito, baixa performance, desligamento) servem para entrevista comportamental e não viram marcador de CV; delas só entra o resultado para o time.
